Gửi app lên Web Store

Kéo thư mục game hoặc tiện ích vào, điền vài thông tin và bấm gửi. Không cần tài khoản GitHub.

Trang gửi app chưa được kết nối với server. Chủ Web Store cần điền địa chỉ server vào file config.js.

1Chọn app

Kéo thả thư mục app vào đây Hoặc một file .html, hoặc file .zip. Thư mục phải có index.html.
